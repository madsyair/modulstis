# Buku Pedoman `modulstis`

`Pedoman_modulstis.pdf` adalah Buku Pedoman
*Aplikasi modulstis: Paket R Penyusun Modul Praktikum dan Kunci Jawaban dari Satu Spesifikasi*. Buka dari R dengan:

```r
modulstis::buka_pedoman()
```

Sumber Quarto buku ini, beserta skrip untuk membangunnya ulang, ada di folder `pedoman/`
repositori paket: <https://github.com/madsyair/modulstis/tree/main/pedoman>.
